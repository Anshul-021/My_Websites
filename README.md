# Weather, at a glance!

A responsive single-page weather app with current conditions, an animated weather scene, city imagery, practical tips, and a three-day forecast.

## WeatherAPI key

The public source keeps `YOUR_WEATHERAPI_KEY` as a placeholder so your private key is not exposed in this public repository. To run a local copy, add your key to `index.html` on your own computer and do not commit that changed file. A public phone-friendly website needs a server-side proxy or another secure hosting setup; GitHub Pages serves static files and cannot keep a browser-side API key private.
